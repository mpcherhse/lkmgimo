# Правила для ИИ-агентов (Claude Code, Codex и др.)

Проект — **концепт** личного кабинета студента «Цифровой деканат» для конкурса. Не официальный сервис вуза.

## Жёсткие правила
- Только вымышленные данные. Никаких реальных ФИО, телефонов, почт (домены — `example.org`), номеров документов.
- Без официального логотипа и фирменных знаков вуза. В интерфейсе, PDF-справках и календаре всегда видна пометка «концепт, данные вымышлены».
- Секреты (ключ шифрования, пароли базы, пароли демо-аккаунтов, секрет TOTP) — только в переменных окружения / `.env` (вне репозитория). Ни в коде, ни во фронтенде, ни в localStorage.
- Пароли — только хэш Argon2id. Токены (сеанс, лента календаря, пароли приложений) — в базе только SHA-256.
- Любой запрос к данным фильтруется по пользователю из сеанса. Чужая запись → 404 (не 403: не подтверждаем, что запись есть). Сотрудник — только свои факультеты.
- Изменяющие запросы: тот же origin + заголовок `x-lk-request: 1`. Тела запросов — строгие модели (`extra="forbid"`).
- Каждое изменение API → тест в `backend/tests/` (особенно `test_isolation.py`: обход маршрутов с чужими id).

## Структура
- `backend/app/` — FastAPI. `auth/` вход, сеансы, 2FA; `routes_student.py`, `routes_staff.py`; `calendar_feed.py` (ICS), `caldav.py` (CalDAV только чтение); `certificates.py` (PDF + проверка); `grading.py` (рейтинг вуза); `seed.py` (демо-данные).
- `backend/migrations/*.sql` — схема (применяется при старте по порядку).
- `frontend/` — React + TypeScript + Vite, свои CSS-токены, без UI-китов.
- `docs/` — SPEC (что делает продукт), ARCHITECTURE, SECURITY, PROCESS_LOG (журнал работы с ИИ).

## Команды
```sh
# база для разработки: Postgres 17 на 127.0.0.1:5460 (lk / lk_test)
cd backend && set -a && . ../../.env && set +a
python -m app.cli seed --reset          # демо-данные
uvicorn app.main:app --port 8800 --reload
python -m pytest -q tests               # тесты на базе lk_test
cd frontend && npm run dev              # фронтенд с прокси на :8800
```

## Стиль интерфейса
Утилитарный, как у ЛК крупных вузов: светлый фон, белые карточки, один тёмно-синий акцент + сдержанный красный для важного.
Без градиентов, стеклянных эффектов, эмодзи, «геройских» блоков, декоративных иллюстраций. Текст — коротко и по делу, по-русски.
Должно работать от 360 px до 1920 px без горизонтального скролла, в том числе на ноутбуках 1280×720 и 1366×768.
